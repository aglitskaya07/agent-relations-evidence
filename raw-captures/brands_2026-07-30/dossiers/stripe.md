## NOT-A-SERVER

`tools/modelcontextprotocol` — not an MCP server implementation, but a thin stdio↔HTTP proxy to the hosted Stripe server `https://mcp.stripe.com`.

Justification (the `src/index.ts` file, 115 lines, the entire source of the `@stripe/mcp` package):

```ts
const MCP_SERVER_URL = 'https://mcp.stripe.com';
...
const stdioTransport = new StdioServerTransport();
...
const transport = new StreamableHTTPClientTransport(
  new URL(MCP_SERVER_URL),
  {requestInit: {headers}}
);
...
transport.onmessage = async (message) => { await stdioTransport.send(message); };
...
stdioTransport.onmessage = async (message) => { ... await httpTransport!.send(message); };
```

There is neither `new Server(...)` / `new McpServer(...)` nor `registerTool` / `server.tool(` / `setRequestHandler` in this directory. The package only forwards JSON-RPC messages between a stdio client and a remote HTTP endpoint; the `initialize` response, the tool list, and all their descriptions come from the Stripe server over the network and are not present statically in the repository.

`server.json` confirms: the server is declared as remote-only.

```json
{
  "name": "com.stripe/mcp",
  "description": "MCP server integrating with Stripe - tools for customers, products, payments, and more.",
  "version": "0.2.4",
  "remotes": [ { "type": "streamable-http", "url": "https://mcp.stripe.com" } ]
}
```

Adjacent directories of the same repository (`tools/typescript/src/modelcontextprotocol/toolkit.ts`, `tools/python/stripe_agent_toolkit/*`) are also proxy wrappers: they are connected by the client to `mcp.stripe.com`, fetch the tool list and reregister it locally, substituting the description received over the network:

```ts
const remoteTools = this._mcpClient.getTools();
for (const remoteTool of remoteTools) { this.registerProxyTool(remoteTool); }
...
this.tool(remoteTool.name, remoteTool.description || remoteTool.name, zodShape, async (...) => {...});
```

Python analogue: `description=mcp_tool.get("description", mcp_tool["name"])` (langchain/crewai/openai/strands toolkits).
